# Contributing to sorowatch-frontend

## Setup
```
npm install
npm run lint
npm run build
npm run dev
```

## Before opening a PR
- Run lint and build and make sure they pass.
- Keep the PR scoped to one issue; reference it with `Closes #N`.

## Related repos
- sorowatch-backend — API this dashboard fetches from
- sorowatch-ai-agent — scoring service behind the backend
- sorowatch-contract — the on-chain source of truth
